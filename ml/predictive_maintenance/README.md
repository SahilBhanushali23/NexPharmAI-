# Predictive Maintenance Machine Learning Pipeline
- Dataset: AI4I 2020 Predictive Maintenance Dataset
- Target: Machine failure (binary classification)
- Models to train & compare: XGBoost, Random Forest, LightGBM, CatBoost, Logistic Regression
- Imbalance handling: SMOTE
- Evaluation: Precision, Recall, F1, ROC-AUC, Failure Recall, Confusion Matrix
