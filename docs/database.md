# NexPharmAI Database Schema Design

## Database: PostgreSQL 16
Managed using SQLAlchemy 2.0 ORM and Alembic migrations.

## Entity Relational Design
- `users`: User authentication, password hashes, timestamps.
- `roles`: Role definitions (`ADMIN`, `PRODUCTION_MANAGER`, `MAINTENANCE_MANAGER`, `QUALITY_MANAGER`, `OPERATOR`).
- `user_roles`: Many-to-many role association.
- `production_lines`: Physical pharmaceutical manufacturing lines.
- `machines`: Equipment catalog, status (`RUNNING`, `IDLE`, `WARNING`, `CRITICAL`, `MAINTENANCE`, `OFFLINE`), line assignment.
- `machine_readings`: Time-series sensor observations (temperatures, RPM, torque, tool wear).
- `machine_predictions`: Failure probability and binary failure predictions from XGBoost/ML models.
- `anomaly_predictions`: Isolation Forest anomaly score, flag, and severity categorization.
- `machine_health_history`: Longitudinal composite health scores (0-100) and trends.
- `alerts`: System notifications and alarms with acknowledgment and resolution tracking.
- `maintenance_records`: Corrective, predictive, preventive, and emergency work orders.
- `products`: Finished pharmaceutical goods, standard lot sizes, recipes, required raw materials.
- `inventory_materials`: Raw chemical ingredients and packaging materials, stock levels, reorder thresholds, expiry dates.
- `inventory_transactions`: Material additions, reservations, and batch consumptions.
- `production_orders`: Customer/market demand orders, quantities, priorities, target due dates.
- `production_batches`: Discrete manufacturing lots linked to products, assigned machines, and lines.
- `production_schedules`: Optimized job sequences generated by OR-Tools.
- `schedule_revisions`: Versioned historical schedules with change justification notes.
- `quality_predictions`: In-process and batch release quality predictions.
- `demand_forecasts`: 7-day, 30-day, and 90-day time-series projections.
- `audit_logs`: Immutable compliance audit trail tracking all state modifications.
